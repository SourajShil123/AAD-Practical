# Sprint 7 — Designing Reusable Components and Application Layout

## Project Information
- Project: Library Management System
- Domain: Education
- Technology: MERN Stack
- Sprint: 7
- Type: Guided Practical
- Difficulty: Beginner

## Sprint Overview

The purpose of this sprint is to transform the React application into a modular and maintainable project by designing reusable user interface components.

The application layout is improved by refining the Navigation Bar, Footer, Sidebar (if applicable), and commonly used UI components such as buttons, cards, and page headers.

## Learning Objectives

- Understand reusable components in React.
- Design reusable UI components using component-based architecture.
- Improve application layouts using reusable layouts and shared components.
- Separate presentation from page-specific logic.
- Maintain a consistent user interface across multiple pages.
- Organize components using an industry-standard folder structure.

## Prerequisites

Sprint 1 through Sprint 6 should be completed before starting this sprint.

- Component Reusability

## Practical Tasks

1. Create a reusable UI components folder.
2. Develop a reusable Button component.
3. Develop a reusable Card component.
4. Develop a reusable PageTitle component.
5. Improve the Navigation Bar.
6. Improve the Footer.
7. Update existing pages using reusable components.
8. Test component reusability across pages.
9. Push the completed sprint to GitHub.

## Result

The Library Management System frontend is organised around reusable React components and shared application layout elements, providing a cleaner and more maintainable component-based structure.
