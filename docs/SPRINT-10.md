# Sprint 10 — Building Forms, Controlled Components, and Client-Side Validation

## Project Information
- Project: Library Management System
- Domain: Education
- Technology: MERN Stack
- Sprint: 10
- Type: Guided Practical
- Difficulty: Beginner

## Sprint Overview

In this sprint, interactive forms are built in the Library Management System using React Controlled Components and client-side validation.

The application implements project-specific forms for Book Registration and Member Management, where React State manages all input values, form submissions are handled without page reloads, client-side validation checks input integrity, and user-friendly error messages guide the user before data is submitted.

## Learning Objectives

- Understand the role of forms in web applications.
- Develop forms using controlled components.
- Capture and manage user input using React State.
- Perform client-side validation before form submission.
- Display validation messages and improve user experience.
- Organize form components following React best practices.

## Practical Tasks

1. Design a project-specific Book Registration form.
2. Implement controlled components with React State.
3. Capture user input using synchronized state variables.
4. Handle form submission preventing default page refresh.
5. Apply client-side validation rules (required fields, character length, ISBN, positive numbers).
6. Display field-specific validation error messages.
7. Reset the form after successful submission and provide a reset button.
8. Test the complete form with valid and invalid inputs.
9. Push the completed sprint to GitHub.

## Result

The Library Management System frontend includes interactive, validated forms using controlled components, ensuring robust client-side validation, error feedback, and seamless data entry workflows.
