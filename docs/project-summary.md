# Project Summary — Library Management System

## Domain
Education

## Technology
MERN Stack

## Purpose
A web-based application for managing books, members, borrowing, returns, and fines through a centralized platform.

## Main Modules
- Authentication & User Management
- Book Management
- Member Management
- Book Borrowing
- Book Return
- Fine Management
- Search & Filter
- Reports & Analytics
- Dashboard

## Scope
The system covers authentication, dashboard operations, book and member management, book issue/borrowing, returns, fine calculation, search, and reports.

## Out of Scope
- Mobile App
- AI recommendation
- Online payment gateway
- Third-party integrations
- E-book reading
