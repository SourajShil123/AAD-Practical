# Sprint 6 — Navigation Testing

## Testing Objective

Verify that the Library Management System frontend navigates correctly between the defined React Router pages.

## Test Cases

| Test | Expected Result |
|---|---|
| Open `/` | Home page is displayed |
| Open `/login` | Login page is displayed |
| Open `/dashboard` | Dashboard page is displayed |
| Open `/profile` | Profile page is displayed |
| Open `/books` | Books page is displayed |
| Open `/members` | Members page is displayed |
| Open `/borrowing` | Borrowing page is displayed |
| Open `/returns` | Returns page is displayed |
| Open `/fines` | Fines page is displayed |
| Open an invalid URL | NotFound page is displayed |

## Browser Verification

- Navigation links were checked.
- Direct URL navigation was checked.
- Browser back and forward navigation was checked.
- Invalid URL handling was checked.
- Browser console should contain no errors.

## Result

The Sprint 6 navigation structure is documented and ready for verification in the running React application.
