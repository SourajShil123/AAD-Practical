# Sprint 9 — Working with React State, Props, and Event Handling

## Project Information
- Project: Library Management System
- Domain: Education
- Technology: MERN Stack
- Sprint: 9
- Type: Guided Practical
- Difficulty: Beginner

## Sprint Overview

In this sprint, the React application is made interactive by implementing Props, State, and Event Handling.

The application transitions from displaying static content to passing data dynamically between components, managing changing information within components using the useState Hook, and responding to user actions such as button clicks and input changes.

## Learning Objectives

- Understand the purpose of Props and State in React.
- Pass data between parent and child components using Props.
- Manage component state using the useState Hook.
- Handle user events such as button clicks and input changes.
- Display dynamic content based on state changes.
- Apply React's one-way data flow in a practical application.
